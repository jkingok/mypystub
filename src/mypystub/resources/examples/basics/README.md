# Basics

Small scripts that show how a prototype runs.

- **hello_world** and **hello_you** print, and read input.
- **console** is the standard library's full Python console: blocks such as `def` work, and `exit()` leaves it.
- **repl** is a tiny Python prompt: type a line, see the result. Variables persist, and `exit()` ends it.
- **show_args** and **show_env** print the arguments and environment variables a script was given. Swipe right on a script and choose **Setup** to set them. Environment variables set on the **Setup** tab's **Environment** page reach every script.
- **args_and_env** greets each name given as an argument, using `GREETING` if it's set.
- **with_dependency** installs a package from PyPI on its first run.
- **Hello Project** is a project folder with its own `pyproject.toml`.

Swipe left on any row for **Info**. On a folder, Info shows its README, like this one.
